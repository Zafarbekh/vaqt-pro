# Vaqt: APK yig'ish (kompyuter yoki telefon brauzeri, Android Studio kerak emas)

1. github.com da bepul akkaunt oching va yangi repozitoriy yarating (nomi: vaqt, Private bo'lsa ham bo'ladi).
2. Shu papkadagi BARCHA fayllarni yuklang (Add file > Upload files). `.github` papkasi ham kirishi shart.
3. Repozitoriyda Actions bo'limiga kiring > "APK yig'ish" > Run workflow. 5-8 daqiqa kuting.
4. Tugagach, o'sha ishga bosing, pastdagi Artifacts ichidan "Vaqt-APK" ni yuklab oling (zip, ichida app-debug.apk).
5. APK ni telefonga o'tkazib o'rnating (sozlamalarda "noma'lum manbalardan o'rnatish"ga ruxsat bering).
6. Birinchi ochganda joylashuv, kamera va xabarnoma ruxsatlarini bering.
